Para restaurarlos en otro equipo, descargue cada CSV desde su enlace en este directorio.

La práctica retoma los modelos y transformaciones de las Prácticas 1 y 2.
Estos CSV son las fuentes sin tratar; aquí no se generan datos procesados ni modelos.
